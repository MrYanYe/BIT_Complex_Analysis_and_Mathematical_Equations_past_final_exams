# BIT_Complex_Analysis_and_Mathematical_Equations_past_final_exams
北京理工大学（北理工、北理、BIT、Beijing Institute of Technology）复变函数与数理方程（复变函数、数理方程、复变函数与积分变换、数学物理方程与特殊函数）往年期末试题。信电、集电、信息与电子学院、集成电路与电子学院，大二上。最新到2022年。

注意这里有三门课，分别是
1. 复变函数与数理方程
2. 复变函数
3. 数理方程

我自己上的是复变函数与数理方程，合起来的，3学分，是集电和信电上的。

另外两门课我也弄来的一些题，考**复变函数与数理方程**的同学也可以参考。单独考《复变函数》或《数理方程》的同学也可以看看，但可能数理方程的题不太新，到2016年；复变函数的题到2022级的，还比较新。
